# 序日 Daynote

一个本地运行的 Windows 计划工具。白色磨砂界面搭配深灰色选中状态，四象限安排任务，最小化后以紧凑待办板继续留在桌面。

## 功能

- 在四象限内直接输入任务，不区分工作和生活。
- 日期计划、完成状态、历史记录，以及按截止日期计算的本周执行率。
- 当前阅读、本周总结、可自定义的本周目标与总目标。
- 可修改标题、寄语、象限说明等界面文案。
- 主窗口与待办板同步；待办板可拖动、调整大小和选择置顶。
- 本地保存、上一份有效数据备份、JSON 导入导出。
- 自选数据目录；程序的缓存、日志、临时文件随数据目录存放。

## 使用

下载 Windows x64 ZIP，解压整个文件夹到你选择的位置，再运行 `Daynote.exe`。不要只复制 EXE 文件。首次运行从空白数据开始。

也可以使用安装版，在安装向导中选择安装目录。请使用当前用户可写的文件夹。

默认目录结构：

```text
Daynote/
  Daynote.exe
  daynote.config.json       # 数据目录与窗口设置
  data/
    state.json             # 任务、阅读、目标、自定义文案
    state.backup.json      # 上一份有效数据
    backups/               # 导入操作前的备份
    runtime/               # 应用缓存、日志、临时文件
```

左下角设置可选择新的空数据目录。应用复制任务和备份后重新启动；原目录保留，运行缓存不复制。更换位置前不会删除原数据。

卸载安装版只移除程序文件，保留数据目录和 `daynote.config.json`。清理数据前请先导出备份。开发时请勿在 `dist/win-unpacked` 保存日常数据，构建工具会重建这个目录；请把整个文件夹复制到独立位置后使用。

主窗口的最小化和关闭按钮都会显示待办板。关闭待办板会收起到托盘；从托盘右键菜单退出应用。

任务默认安排在选中的日期，截止日期同为这一天；点击任务可分别修改计划日期与截止日期。未完成任务不会在跨天时被自动改期。

本周按当地时间的周一到周日计算：**本周截止且已完成的任务数 ÷ 本周截止的全部任务数**。没有本周计划时显示 `—`。目标板块的百分比单独维护，不随任务完成自动变化。

## 环境与限制

- 目标平台：Windows 10/11 x64。Windows 11 22H2 及以上可使用系统 Acrylic 背景；其他版本使用白色底色。
- 桌面待办板是独立窗口，可选置顶；暂未嵌入 Windows 桌面层，使用“显示桌面”可能会将其一起隐藏。
- 无账号、遥测、云同步和运行时网络请求。
- 应用主动管理的数据、缓存、日志放在选定目录。Windows 生成的最近使用记录、预读取文件等由系统管理，不能保证系统盘完全零写入。
- 测试版未签名，可能显示发布者未知。开源代码采用 MIT；Electron/Chromium 等依赖保留自己的许可证。
- 本地数据使用可读 JSON，不提供加密。请自行保护设备及备份。

## 开发

使用 Node.js 24 或以上。依赖版本固定在 `package.json` 和 `package-lock.json`。PowerShell 开发脚本将下载、Electron、打包缓存与临时文件设置到项目目录下，避免默认占用系统盘。

```powershell
./scripts/dev.ps1 install
./scripts/dev.ps1 test
./scripts/verify-desktop.ps1
./scripts/dev.ps1 start
./scripts/dev.ps1 pack
./scripts/dev.ps1 dist
```

`pack` 生成 `dist/win-unpacked/Daynote.exe`；`dist` 另外生成 ZIP 和支持自选安装目录的 NSIS 安装包。发布包不包含个人数据、缓存和开发工具。

源码结构：

```text
src/main.cjs       原生窗口、托盘、数据目录和受限 IPC
src/preload.cjs    界面与桌面能力之间的最小桥接
src/store.cjs      校验、原子写入、恢复和备份
src/renderer/     界面、样式和交互
tests/            数据完整性与桌面集成测试
```
